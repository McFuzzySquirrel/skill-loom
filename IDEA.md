# Project Idea

The idea is to have a local UI where users can find installed global skills, select the ones they want to run and the order in which they want to run them. The user should be able to see what they do to help select the right ones. When they have the order loaded, they should be able to execute them in a harness (opencode CLi and copilot CLi for now) in an interactive xterm terminal in the UI. As a start they would either need to select an existing project or create a new one
